# Dependabot alert 83: minimatch

Approved scope: [alert 83](https://github.com/cloudshare/cloudshare-demo-portal/security/dependabot/83), using an exact npm override from `@typescript-eslint/typescript-estree` to `minimatch` 11.0.1. The lockfile changes only that nested package and its new `@isaacs/nonrecursive-glob-match` dependency. Preserve the `@prisma/config` → `deepmerge-ts` 8.0.0 and Next/PostCSS overrides and Vite 6.4.5. No application, schema, shared checkout, database, server, or live CloudShare changes.

GHSA-g3hv-75wg-m249 / CVE-2026-118764 describes excessive pattern expansion and quadratic preprocessing at `optimizationLevel >= 2`. The baseline parser resolves minimatch 10.2.5. Its actual call in `useProgramFromProjectService.js` is `minimatch(filePath, pattern, { dot: true })`, for `allowDefaultProject` patterns; it retains default optimization level 1. No remote portal exposure through this call was identified.

This override crosses a major version outside the parser's declared `^10.2.2` range. Version 11 removes `makeRe`, `AST`, several internal methods/options, and changes `Minimatch.set` entries from regular expressions to matcher objects. It also changes some empty-path, globstar, and Windows path semantics. The parser uses the retained named `minimatch` function and boolean result, not those removed APIs. Its installed source was inspected; representative matching and normal lint/build checks cover the relevant compatibility seam. These checks do not prove every possible user-supplied glob is equivalent. Retire the override when the parser's supported dependency range includes a patched version.

The approved temporary harness lives under ignored `runtime/alert83/`, not in permanent version-assertion tests. Using the public `Minimatch` constructor with twelve `**/../a/b` sections, `optimizationLevel: 2`, and `braceExpandMax: 64`, it asserts the public compiled set stays within the requested cap. A child process bounds execution to five seconds and 128 MiB. Baseline 10.2.5 fails with 4096 entries; 11.0.1 passes (4 ms observed). `braceExpandMax` already exists in v10.2, but the patch extends the cap to this optimization expansion. Six calls through the same named function and `{ dot: true }` options as the parser pass before and after: node_modules inclusion/exclusion, hidden paths, and TypeScript/TSX brace patterns with JavaScript exclusion. This is bounded evidence of the advisory fix, not an unbounded resource-exhaustion attempt.

Validation: clean `npm ci`, Prisma client generation, lint, typecheck, full tests, isolated fixture-mode production build, dependency tree, and `npm audit`. Exact results and independent review/QA evidence are recorded on PR #507. Audit after the override reports zero vulnerabilities; the intended existing overrides remain resolved. Build configuration uses synthetic values and an isolated database path, with seeding/background jobs disabled. Human QA and live CloudShare verification are not required for this development-tool dependency change; there is no UI or active integration behavior change. No merge is authorized by this remediation request. Alert 83 is not GitHub issue 83.
