# Domain docs

This is a single-context repository. Before exploring, read `CONTEXT.md` for the canonical glossary, the relevant ADRs in `docs/decisions/`, and `docs/requirements/prd-cloudshare-demo-portal-v2.md` for scope.

Use those paths wherever engineering skills refer generically to `GLOSSARY.md` or `docs/adr/`. Keep the existing documents in place; avoid duplicate glossaries or decision trees. Use the glossary vocabulary in issues, proposals and tests. Note real terminology gaps for domain modeling, and explicitly flag any proposal that contradicts an existing ADR rather than silently overriding it.

If an optional domain document is absent, proceed without creating placeholders. Preserve decisions and their history in this repository.
